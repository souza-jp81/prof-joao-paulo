📌 Sobre o projeto

O Portal Acadêmico — Prof. João Paulo é uma aplicação web criada para organizar e disponibilizar materiais de aula, artigos, PDFs, roteiros de estudo e conteúdos acadêmicos relacionados à Fisioterapia e às Ciências da Saúde.

O projeto une duas áreas da trajetória profissional do autor: docência e desenvolvimento web, transformando materiais acadêmicos em uma experiência digital organizada, pesquisável e responsiva.

A aplicação possui uma página institucional e uma central de materiais com recursos interativos implementados em JavaScript puro.

🎯 Objetivos

Centralizar materiais acadêmicos em um único ambiente.

Facilitar o acesso dos estudantes aos conteúdos das disciplinas.

Permitir busca e filtragem de materiais.

Organizar arquivos por áreas de estudo.

Oferecer uma interface moderna e responsiva.

Aplicar desenvolvimento web a uma necessidade real da educação em saúde.

✨ Funcionalidades

✅ Página inicial de apresentação acadêmica.

✅ Central de materiais e downloads.

✅ Busca de materiais em tempo real.

✅ Filtros por categoria.

✅ Contador dinâmico de resultados.

✅ Alternância entre visualização em grade e lista.

✅ Sistema de favoritos com localStorage.

✅ Tema claro e escuro com persistência.

✅ Menu responsivo para dispositivos móveis.

✅ Fechamento do menu por clique externo ou tecla Esc.

🛠️ Tecnologias utilizadas

HTML5 — estrutura e conteúdo semântico.

CSS3 — design, responsividade, animações e temas.

JavaScript — comportamento e recursos interativos.

LocalStorage — persistência local de tema e favoritos.

Font Awesome — biblioteca de ícones.

Google Fonts — tipografia da interface.

O projeto não depende de framework JavaScript nem de processo de build.

🔎 Busca e filtros

A central de materiais combina categoria e texto pesquisado para atualizar automaticamente os cards visíveis, a quantidade de resultados e o estado de “nenhum resultado”.

⭐ Sistema de favoritos

Os materiais marcados como favoritos são armazenados no navegador em localStorage, permitindo persistência local após recarregar a página.

🌙 Tema claro e escuro

A preferência visual do usuário também é persistida no navegador, e o portal reaplica automaticamente o tema escolhido nas visitas seguintes.

📱 Responsividade

A interface possui navegação adaptada para dispositivos móveis, menu hamburger, backdrop e suporte ao fechamento com Esc.

▶️ Como executar

Por ser uma aplicação estática, não é necessário instalar dependências.

git clone https://github.com/souza-jp81/prof-joao-paulo.git
cd prof-joao-paulo

Abra index.html diretamente no navegador ou utilize uma extensão como Live Server no VS Code.
